# بينغ بونغ 🏓

عدّاد خفيف لبينغ بونغ، بيشتغل عالآيفون من Safari ← مشاركة ← "إضافة إلى الشاشة الرئيسية".

## القواعد
- **الدق**: ١١ نقطة، ولازم تفرق نقطتين (بعد ١٠–١٠).
- **الخمسة الصغيرة**: أول واحد بيربح ٣ دقوق من ٥.
- **الخمسة الكبيرة** 🏆: أول واحد بيربح ٣ خمسات صغيرة من ٥.

## الاستعمال
- دق على نص اللاعب = نقطة إله.
- ↶ تراجع: بيرجع آخر نقطة (حتى لو خلص فيها دق).
- ⇄: بيبدّل الجهات.
- ⋯: تغيير الأسامي، خمسة كبيرة جديدة، تصفير.
- 🏓 إرسال: بيوضح مين عليه الإرسال. على ٠–٠ فيك تدق عليه لتغيّر مين بيبلّش.

كل شي بينحفظ عالموبايل، فلو سكرت التطبيق بترجع لنفس النتيجة.

ملف واحد `index.html` بدون أي build، بتحطه على أي استضافة static.
