# بينغ بونغ 🏓

عدّاد خفيف لبينغ بونغ، بيشتغل عالآيفون من Safari ← مشاركة ← "إضافة إلى الشاشة الرئيسية".

## القواعد
- بآخر كل دق بتكبس "فاز بالدق" تحت اسم اللي ربح، وما في عدّ نقاط.
- **الخمسة الصغيرة** ⭐: أول واحد بيربح ٣ دقوق.
- **الخمسة الكبيرة** 🏆: أول واحد بيربح ٣ خمسات صغيرة. هي الكأس.

## الاستعمال
- اكبس على اسم اللاعب لتختار مين بيلعب، أو لتضيف لاعب جديد.
- 🏆 الترتيب: كل اللاعبين مع كؤوسهم وخمساتهم الصغيرة ودقوقهم. ✏️ لتغيير الاسم أو المسح.
- ↶ تراجع: بيرجع آخر كبسة.
- التقدّم بينحفظ لكل تنين لحالهم، فإذا بدّلت الخصم ورجعت بتكمّل من وين وقفت.

كل شي بينحفظ عالموبايل للأبد (استعمله من أيقونة الشاشة الرئيسية).

ملف واحد `index.html` بدون أي build، بتحطه على أي استضافة static.
